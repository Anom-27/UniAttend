# LaTeX source of the proposal

- `main.tex` is the full proposal (generated from `proposal_body.md`), `figures/` holds all diagrams and screenshots.
- Build: `xelatex main.tex` (run twice for the table of contents). The finished PDF is `../docs/UniAttend_Proposal.pdf`.
- To use the university template later: copy the text of `proposal_body.md` into the template and keep the `figures/` folder.
